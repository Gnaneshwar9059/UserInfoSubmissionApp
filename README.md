# User Information Submission App

A Windows Forms application built with .NET 8 that allows users to log in, submit personal information, view their submission history, update duplicate records, and delete submissions.

## Tech Stack
- .NET 8
- Windows Forms
- SQLite
- Dapper
- Dependency Injection
- MSIX Packaging

## Features
- User login
- Submit user information
- Duplicate detection with overwrite
- View submission history
- Delete submissions
- SQLite local database

## Installation

Download the `.msix` installer and install it on Windows 10/11.

If Windows reports an untrusted publisher, install the included `.cer` certificate first.
